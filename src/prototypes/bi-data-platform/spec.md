# BI数据管理平台 - 产线日常数据

## 📋 业务与功能

### 1.1 核心目标
> 为制造企业提供产线级别的数据可视化与分析能力，覆盖 OEE（设备综合效率）、FTT（一次通过率）、达产率、产线节拍、异常管理、运营数据及环境能耗等核心维度，辅助产线管理者快速定位问题、优化生产效率。

### 1.2 功能清单

- **产线筛选**：顶部下拉选择产线（电驱一线~五线、电控、定转子、电源、油泵、压缩机），支持快速切换
- **OEE明细**：展示实际OEE(MES) 86%、子指标（负荷时间、稼动时间、时间稼动率、性能稼动率、达产率），按 EOL站/下线站统计的 OEE 走势图（目标 vs 实际）
- **FTT明细**：展示实际FTT(下线) 99.38%，FTT 趋势图（实际 vs 目标）
- **达产率明细**：展示达产率趋势及明细数据
- **产线节拍明细**：工位节拍平衡分析表（序号、工位号、工位名称、过站总产品数、标准/实际节拍），产线平衡率 86%，节拍异常产品数、瓶颈工序标识
- **产线异常明细**：产线异常事件列表，支持筛选查看
- **运营数据**：负荷时间、稼动时间、非计划停机时间的趋势与明细
- **环境能耗数据**：温湿度趋势图、温湿度明细表（在线表格支持增删改），含点检时间、温度℃、湿度%、点检位置、班次

### 1.3 交互要点

- 产线切换：选择不同产线 → 所有数据区域联动刷新
- Tab 切换：点击子Tab → 切换对应数据视图，保持产线选择状态
- 环境能耗表格：支持行内编辑、新增行、删除行操作
- 图表悬停：ECharts tooltip 显示详细数据
- 表格排序：支持列头排序

### 2.2 数据来源

- **数据类型**：生产制造数据、设备运行数据、环境检测数据
- **数据源**：生成示例数据（制造业真实场景兜底）
- **关键字段**：
  - `productionLine`: 产线名称
  - `oee`: 设备综合效率（%）
  - `ftt`: 一次通过率（%）
  - `loadTime`: 负荷时间（min）
  - `operationTime`: 稼动时间（min）
  - `downtimeTime`: 非计划停机时间（min）
  - `taktStandard`: 标准节拍（s）
  - `taktActual`: 实际节拍（s）
  - `temperature`: 温度（℃）
  - `humidity`: 湿度（%）
  - `checkTime`: 点检时间
  - `checkPosition`: 点检位置
  - `shift`: 班次

### 2.3 内容示例

**产线列表**：电驱一线、电驱二线、电驱三线、电驱四线、电驱五线、电控产线、定转子产线、电源产线、油泵产线、压缩机产线

**OEE指标示例**：实际OEE(MES) 86%、目标OEE 90%、负荷时间 480min、稼动时间 412.8min、时间稼动率 86%、性能稼动率 95.2%、达产率 93.5%

**工位节拍示例**：工位 OP10-铣削端面（标准 42s / 实际 45s）、OP20-钻孔（标准 38s / 实际 37s）、OP30-攻丝（标准 35s / 实际 41s，瓶颈工序）

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：顶部导航 + 内容区网格布局
- **容器宽度**：流式布局，最大宽度 1440px
- **关键尺寸**：
  - 顶部导航栏：高度 56px
  - Tab 导航栏：高度 46px
  - 指标卡片区域：Row + Col 网格，4列（25%）
  - 图表区域：全宽，高度 350px
  - 表格区域：全宽

### 3.2 响应式适配

- **桌面端（≥1200px）**：4列指标卡片，图表全宽
- **平板端（768-1199px）**：2列指标卡片
- **移动端（<768px）**：单列布局

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：主题 `/src/themes/antd-new`

**说明**：基于 Ant Design v6 设计系统，使用其 Design Token 体系。Primary #1677ff，Success #52c41a，Warning #faad14，Error #ff4d4f。采用 Card + Table + ECharts 组合构建数据密集型界面。

### 4.2 自定义设计要点

**自定义色彩**：
- OEE 达标色：#52c41a - OEE 达到目标值时的标识
- OEE 未达标色：#faad14 - OEE 低于目标值时的标识
- 瓶颈工序色：#ff4d4f - 产线节拍中瓶颈工序标识
- 平衡率良好色：#1677ff - 产线平衡率 70%-80% 区间

### 4.3 组件状态

- **默认态（default）**：数据正常展示
- **悬停态（hover）**：表格行高亮、卡片微阴影、按钮状态变化
- **加载态（loading）**：Skeleton 骨架屏占位
- **空状态（empty）**：无数据时显示 Empty 组件
