# IPD交付物管理系统

## 📋 业务与功能

### 1.1 核心目标
> 简要说明该组件/原型的核心定位、解决的问题、用户价值

IPD交付物管理系统是一个企微端小程序，用于管理项目交付物和项目信息，方便用户在移动端查看和管理相关内容。系统解决了用户在移动端快速访问和管理交付物与项目信息的问题，提升了工作效率。

### 1.2 功能清单
> 列出所有功能模块及其优先级

- **交付物列表**：查看所有交付物、待办交付物、已办交付物，支持搜索交付物名称
- **项目管理**：查看项目列表，支持搜索项目名称
- **我的**：查看个人信息，包括工号、姓名、部门和头像

### 1.3 交互要点
> 关键的交互触发点、反馈机制、状态变化

- 底部导航切换：点击底部导航栏切换不同模块
- 状态筛选：点击交付物列表顶部的状态标签切换不同状态的交付物
- 搜索功能：在搜索框输入关键词搜索相关内容
- 列表项点击：点击交付物或项目列表项查看详情
