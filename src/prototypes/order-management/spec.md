# 订单管理 - 订单列表页面

## 📋 业务与功能

### 1.1 核心目标
为电商运营人员提供一个功能完善的订单管理界面，支持订单查询、筛选、批量操作和详情查看。通过清晰的订单状态展示和便捷的操作入口，提升订单处理效率，降低运营人员的工作负担。

### 1.2 功能清单

**订单列表页面**
- **[P0] 搜索筛选**: 订单号、买家手机号、状态下拉、渠道下拉、时间区间
- **[P0] 快捷操作**: 导出 CSV、批量发货按钮
- **[P0] 订单表格**: 复选框、订单号、下单时间、买家信息、渠道、商品概览、金额信息、状态标签、操作列
- **[P0] 分页排序**: 支持分页浏览和列排序
- **[P0] 行选中**: 支持多选，选中后批量发货按钮激活
- **[P1] 悬浮操作**: 操作列在行悬浮时显示（查看、改价、发货、退款、关闭、售后、备注）

**订单详情抽屉**
- **[P0] 基本信息**: 订单号、状态、渠道、下单时间、买家、收货信息、支付方式、金额、备注
- **[P0] 商品列表**: 商品图、标题、规格、单价、数量、小计、单品优惠
- **[P0] 费用明细**: 商品总额、优惠、运费、实付金额
- **[P0] 物流信息**: 物流公司、快递单号、发货时间
- **[P0] 售后记录**: 售后单号、类型、状态、申请时间、金额
- **[P0] 操作按钮**: 改价、发货、退款、关闭订单、添加备注

**异常订单 Tab**
- **[P0] 异常筛选**: 只展示 exceptionTag !== NONE 的订单
- **[P0] 行背景色**: 根据标签区分（红色-付款超时、橙色-发货延迟、黄色-库存短缺）
- **[P0] 快捷操作**: 立即关闭、手动发货、补库存
- **[P1] 批量处理**: 对选中行执行相同操作

### 1.3 交互要点

- **搜索验证**: 点击搜索时若所有字段为空，弹出提示"请至少输入一个查询条件"
- **行悬浮**: 鼠标悬浮在表格行上时，操作列显示操作按钮
- **批量操作**: 选中多行后，批量发货按钮激活，点击后弹出确认框
- **发货弹窗**: 输入物流公司、快递单号，提交后调用发货接口
- **改价弹窗**: 输入新实付金额，校验 newAmount >= 0 && newAmount >= orderCostTotal
- **错误处理**: 所有接口错误统一使用 message.error(err.msg || '操作失败')
- **成功反馈**: 操作成功后 message.success('操作成功')，并自动刷新列表

### 2.2 数据来源

- **数据类型**: 订单列表数据
- **数据源**: `/assets/database/orders.json` 作为示例数据参考
- **API 接口**: 
  - GET `/api/v1/orders` - 获取订单列表（带分页、过滤）
  - GET `/api/v1/orders/{orderNo}` - 获取订单详情
  - PUT `/api/v1/orders/{orderNo}/price` - 提交改价
  - POST `/api/v1/orders/{orderNo}/ship` - 提交发货
  - POST `/api/v1/orders/{orderNo}/refund` - 提交退款
  - POST `/api/v1/orders/{orderNo}/close` - 关闭订单

**订单数据字段**:
- `orderNo`: 订单号
- `createTime`: 下单时间
- `buyerNick`: 买家昵称
- `buyerPhone`: 买家手机号
- `channel`: 渠道（APP/小程序/PC）
- `items`: 商品列表（最多显示2条）
- `payAmount`: 实付金额
- `freight`: 运费
- `discount`: 优惠金额
- `status`: 订单状态
- `afterSaleStatus`: 售后状态
- `exceptionTag`: 异常标签

### 2.3 内容示例

**订单状态枚举**:
- `PENDING_PAY`: 待付款
- `PAID`: 已付款
- `WAIT_SHIP`: 待发货
- `SHIPPED`: 已发货
- `RECEIVED`: 已收货
- `COMPLETED`: 已完成
- `CLOSED`: 已关闭
- `REFUNDED`: 已退款

**售后状态枚举**:
- `NONE`: 无售后
- `APPLYING`: 申请中
- `PROCESSING`: 处理中
- `COMPLETED`: 已完成
- `REJECTED`: 已拒绝

**异常标签枚举**:
- `NONE`: 正常
- `PAY_TIMEOUT`: 付款超时（红色）
- `SHIP_DELAY`: 发货延迟（橙色）
- `STOCK_SHORTAGE`: 库存短缺（黄色）

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**: 左侧导航 + 右侧内容区，订单列表采用卡片式单栏布局
- **容器宽度**: 100% 流式布局，主内容区自适应
- **页面结构**:
  - 左侧导航栏（订单管理 / 商品管理 / 库存管理）
  - 页面标题区（标题 + 描述）
  - 白色主卡片容器
    - 顶部 Tab 切换栏（全部订单 / 异常订单）
    - 统计卡片区（仅全部订单 Tab）
    - 异常提示条（仅异常订单 Tab）
    - 搜索筛选区
    - 工具栏（数据统计 + 快捷操作）
    - 订单表格
    - 底部分页器

**关键尺寸**:
- 侧边栏宽度: 220px
- 主卡片圆角: 12px
- 搜索区: 浅灰背景面板，表单元素间距 16px
- 表格: 圆角边框包裹，行悬浮浅蓝背景
- 操作列: 行悬浮时按钮高亮
- 抽屉: 宽度 800px，顶部渐变信息横幅

### 3.2 响应式适配

**桌面端（≥1200px）**:
- 标准后台管理布局
- 表格所有列正常显示
- 抽屉宽度 800px

**平板端（768-1199px）**:
- 表格部分列隐藏（优惠、运费）
- 抽屉全屏显示

**移动端（<768px）**:
- 搜索区改为垂直布局
- 表格简化显示

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**: 主题 `/src/themes/antd-new`

采用 Ant Design 企业级设计系统，符合中后台管理系统设计规范：
- 品牌色: #1677ff（科技蓝）
- 功能色: 成功 #52c41a、警告 #faad14、错误 #ff4d4f
- 中性色: 标题 rgba(0,0,0,0.88)、正文 rgba(0,0,0,0.65)
- 间距: 基于 4px 网格系统

### 4.2 自定义设计要点

**统计卡片**:
- 左侧 4px 色条区分指标类型（蓝/橙/绿/红）
- 悬浮时轻微上浮 + 阴影加深
- 数值使用 tabular-nums 等宽数字

**渠道标签配色**:
- APP: 蓝色系 (#e6f4ff / #1677ff)
- 小程序: 绿色系 (#f6ffed / #389e0d)
- PC端: 紫色系 (#f9f0ff / #722ed1)

**异常订单**:
- 顶部黄色渐变提示条，显示待处理数量
- 行背景色: 付款超时 #fff1f0、发货延迟 #fff7e6、库存短缺 #feffe6
- 商品列内嵌异常标签（图标 + 文字）

**表格视觉**:
- 去除外边框线，使用圆角容器包裹
- 表头浅灰背景 (#fafbfc)，字重 600
- 行悬浮 #f8faff，选中行 #e6f4ff
- 订单号使用等宽字体 + 品牌色

**详情抽屉**:
- 顶部蓝色渐变横幅展示订单号、状态、时间
- 内容区分卡片式区块，左侧蓝色竖线标题
- 费用明细右对齐，实付金额红色加粗

**状态标签颜色**:
- 待付款: 橙色
- 已付款/待发货: 蓝色
- 已发货: 青色
- 已完成: 绿色
- 已关闭/已退款: 灰色

**操作按钮状态**:
- 改价: 仅在 PAID → WAIT_SHIP 状态可用
- 发货: 仅在 PAID → WAIT_SHIP 状态可用
- 退款: 仅在 PAID → WAIT_SHIP / SHIPPED → RECEIVED 状态可用
- 关闭: 非 COMPLETED、CLOSED 状态可用

### 4.3 组件状态

**表格行状态**:
- **默认态**: 白色背景
- **悬浮态**: 浅灰色背景，操作列显示
- **选中态**: 蓝色边框高亮

**按钮状态**:
- **可用态**: 正常颜色，可点击
- **禁用态**: 灰色，不可点击
- **加载态**: Loading 动画

**弹窗状态**:
- **默认态**: 正常显示表单
- **校验错误**: 红色边框提示
- **提交中**: 按钮 Loading，表单禁用

## 📱 页面详细设计

### 订单列表页面

**搜索筛选区**:
- 订单号: Input，placeholder "请输入订单号"
- 买家手机号: Input，placeholder "请输入手机号"
- 订单状态: Select，选项包含所有状态
- 渠道: Select，选项：APP/小程序/PC
- 时间区间: DatePicker.RangePicker
- 搜索按钮: Primary Button

**快捷操作区**:
- 导出 CSV: Default Button，图标 Download
- 批量发货: Primary Button，disabled 直到有选中行

**订单表格列**:
1. 复选框: selection column
2. 订单号: 120px，可排序
3. 下单时间: 150px，可排序
4. 买家: 150px（昵称+手机号）
5. 渠道: 80px，Tag 显示
6. 商品概览: 250px（最多2条，小图+标题+数量）
7. 实付金额: 100px，可排序，红色加粗
8. 运费: 80px
9. 优惠: 80px
10. 订单状态: 100px，Tag 显示
11. 售后状态: 100px，Tag 显示
12. 操作: 200px，悬浮时显示按钮组

### 订单详情抽屉

**顶部操作栏**:
- 改价按钮: 条件渲染
- 发货按钮: 条件渲染
- 退款按钮: 条件渲染
- 关闭订单按钮: 条件渲染
- 添加备注按钮: 始终显示

**基本信息区**:
- 使用 Descriptions 组件，4列布局
- 显示：订单号、状态、渠道、下单时间、买家、收货信息、支付方式、金额、备注

**商品列表**:
- Table 组件，列：商品图、标题、规格、单价、数量、小计、单品优惠

**费用明细**:
- 右对齐显示：商品总额、优惠、运费、实付金额

**物流信息**:
- 若已发货：显示物流公司、快递单号、发货时间
- 若未发货：显示 "未发货" 提示

**售后记录**:
- 若存在售后：Table 显示售后单号、类型、状态、申请时间、金额、操作
- 若无售后：显示 Empty 组件

### 异常订单 Tab

**表格差异**:
- 只显示 exceptionTag !== NONE 的订单
- 行背景色根据异常标签区分
- 操作列显示快捷操作按钮

**快捷操作**:
- 付款超时: 立即关闭按钮
- 发货延迟: 手动发货按钮
- 库存短缺: 补库存按钮

**批量处理**:
- 顶部显示批量处理按钮
- 点击后弹出确认框，列出受影响订单号
