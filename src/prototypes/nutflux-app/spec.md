# NutFlux 视频流媒体 APP

## 📋 业务与功能

### 1.1 核心目标
NutFlux 是一款现代化的视频流媒体移动应用，为用户提供高质量的视频点播（VOD）和直播体验。通过智能推荐算法和个性化内容发现，帮助用户快速找到感兴趣的视频内容。同时提供社交互动功能，增强用户粘性和社区活跃度。

### 1.2 功能清单

**视频播放与浏览**
- **[P0] 视频点播播放**: 支持主流视频格式，流畅播放体验
- **[P0] 自适应码率切换**: 360p/480p/720p/1080p/4K 多档位切换
- **[P0] 播放控制**: 播放/暂停、快进/快退(15s)、音量控制、全屏切换
- **[P1] 多语言字幕**: 支持中英文字幕切换
- **[P1] 历史观看记录**: 自动记录播放进度，支持断点续播
- **[P2] 直播流媒体**: 支持实时直播播放

**内容发现与个性化**
- **[P0] 首页推荐**: 基于用户偏好的智能推荐流
- **[P0] 分类浏览**: 电影/电视剧/综艺/动漫/纪录片等分类
- **[P0] 搜索功能**: 关键字搜索、标签筛选、创作者搜索
- **[P1] 热门榜单**: 实时热门视频排行、趋势内容
- **[P1] 筛选功能**: 按地区、语言、年份、评分筛选

**社交与互动功能**
- **[P0] 点赞/收藏**: 一键点赞，收藏到个人列表
- **[P0] 分享功能**: 分享到社交平台
- **[P1] 评论系统**: 视频评论、回复、点赞评论
- **[P1] 创作者关注**: 关注喜欢的创作者
- **[P2] 通知系统**: 新视频推送、评论回复通知

### 1.3 交互要点

- **视频卡片点击**: 点击进入视频详情页，展示播放器
- **播放控制手势**: 双击暂停/播放，左右滑动快进/快退
- **底部导航切换**: 首页/发现/我的 三个主标签切换
- **下拉刷新**: 首页内容支持下拉刷新获取最新推荐
- **上拉加载**: 列表页支持上拉加载更多内容

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**: 移动端单栏布局，底部固定导航
- **容器宽度**: 100% 流式布局，最大宽度 480px（模拟手机）
- **安全区域**: 顶部状态栏 44px，底部导航栏 56px

**关键尺寸**:
- 视频卡片: 宽度 100%，高度自适应 16:9
- 轮播 Banner: 宽度 100%，高度 200px
- 底部导航: 高度 56px，3个等分标签
- 视频网格: 2列网格，间距 12px

### 3.2 响应式适配

**移动端（<480px）**:
- 标准移动端布局
- 底部固定导航栏
- 视频卡片单列或双列

**平板端（480-768px）**:
- 视频网格调整为 3 列
- 更大的封面图尺寸

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**: 内置 frontend-design

采用深色主题设计，符合视频类应用的视觉习惯：
- 深色背景减少视觉疲劳
- 高对比度文字确保可读性
- 强调色突出主要操作

### 4.2 自定义设计要点

**自定义色彩**:
- 主背景色: #0f0f0f (近黑色)
- 卡片背景: #1a1a1a (深灰)
- 强调色: #e50914 (Netflix 红)
- 文字主色: #ffffff (白色)
- 文字次色: #b3b3b3 (灰色)
- 分割线: #2a2a2a

**自定义尺寸**:
- 圆角: 8px (卡片), 24px (按钮)
- 间距: 16px (标准), 12px (紧凑)
- 字体: 标题 18px, 正文 14px, 辅助 12px

### 4.3 组件状态

**视频卡片状态**:
- **默认态**: 正常显示封面图和标题
- **悬停态**: 封面图放大 1.05 倍，显示播放按钮
- **按下态**: 封面图缩小 0.98 倍

**底部导航状态**:
- **选中态**: 图标和文字显示强调色
- **未选中态**: 图标和文字显示灰色

**按钮状态**:
- **默认态**: 强调色背景，白色文字
- **悬停态**: 背景色加深 10%
- **禁用态**: 灰色背景，不可点击

## 📱 页面详细设计

### 首页 (Home)

**布局结构**:
1. 顶部搜索栏（固定）
2. 轮播 Banner（自动播放）
3. 继续观看（横向滚动）
4. 热门推荐（横向滚动）
5. 新片上架（纵向列表）

**交互说明**:
- 下拉刷新首页内容
- 左右滑动切换轮播图
- 点击视频卡片进入播放页

### 发现页 (Discover)

**布局结构**:
1. 搜索框（带语音输入图标）
2. 分类标签栏（横向滚动）
3. 筛选器（地区/年份/语言）
4. 视频网格（瀑布流布局）

**交互说明**:
- 点击分类标签筛选内容
- 上拉加载更多视频
- 点击筛选器展开选项

### 我的页 (Profile)

**布局结构**:
1. 用户信息卡片
2. 功能列表（历史/收藏/关注）
3. 设置入口

**交互说明**:
- 点击列表项进入对应页面
- 用户信息区域可编辑

### 视频播放页 (Player)

**布局结构**:
1. 视频播放器（全屏或内嵌）
2. 播放控制栏（进度条/播放按钮/音量）
3. 视频信息（标题/简介/标签）
4. 互动按钮（点赞/收藏/分享）
5. 评论区
6. 相关推荐

**交互说明**:
- 双击屏幕暂停/播放
- 左右滑动快进/快退
- 上下滑动调节音量/亮度
- 点击全屏按钮切换全屏模式
