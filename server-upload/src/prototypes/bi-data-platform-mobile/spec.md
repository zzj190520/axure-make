# BI数据管理平台（移动端）

## 📋 业务与功能

### 1.1 核心目标
> PC端 BI 数据管理平台的移动端适配版本，针对手机小屏幕（≤430px）优化交互体验，方便产线管理人员随时随地查看产线运营数据。

### 1.2 功能清单
- **顶部导航栏**：渐变蓝色背景 + Logo + 标题副标题 + 通知铃铛 + 更多菜单
- **上下文信息条**：当前产线 / 日期 / 运行状态 Chip（可点击切换）
- **顶部标签栏**：运营数据 / OEE明细 / …（胶囊式可滑动 Tab）
- **底部导航栏**：产线数据 / 设备管理（badge 12）/ 问题管理（badge 5）/ 我的（毛玻璃 + 选中胶囊底）
- **首页（运营数据）**：Hero 概览卡（综合OEE + 三项摘要）+ 核心指标（2列6卡）+ OEE走势图 + 产地/时间选择
  - **Hero 概览**：产线名 · 今日综合 OEE + 目标对比 + 实际产量/FTT/达产率摘要
  - **核心指标**（2列卡片）：负荷时间、稼动时间、OEE(目标)、FTT(目标)、计划产量、实际产量
- **OEE 明细页**：实际OEE(MES)86%、目标OEE90%、EOL站/下线站走势 + OEE明细表
- **FTT 明细页**：实际FTT(下线)99.38%、目标FTT99.5% + 今日合格/不良品 + FTT趋势图
- **达产率明细页**：达产率99% + 趋势柱状图 + 明细列表（日期/计划/实际/达成率/差异）
- **节拍明细页**：平衡率86%/平均节拍/异常工位/瓶颈工序 + 平衡率进度条 + 工位节拍明细表
- **异常明细页**：筛选标签（设备故障/物料短缺/品质异常/换型停机）+ 异常卡片列表
- **能耗环境页**：温湿度/能耗指标 + 温湿度趋势图 + 可编辑明细列表（增删改）

### 1.3 交互要点
- **顶部导航**：渐变背景，返回/铃铛/更多按钮 active 态反馈
- **上下文 Chip**：产线/日期可点击打开弹窗
- **顶部标签栏**：胶囊式 Tab，选中蓝紫渐变 + 阴影
- **底部导航**：毛玻璃背景，选中图标胶囊底高亮
- **选择产地弹窗**：Modal 弹窗展示 10 条产线列表，点击选中并关闭
- **选择时间弹窗**：Modal 弹窗展示 DatePicker 日期选择器
- **异常筛选**：点击类型标签过滤异常列表，支持单选/取消
- **环境数据编辑**：点击"编辑"行内切换为 InputNumber，OK 保存；支持新增/删除

### 2.2 数据来源
- **数据类型**：Mock 静态数据（与 PC 端共享相同数据模型）
- **数据源**：生成示例数据
- **关键字段**：
  - `HOME_METRICS`：首页 Hero 与核心指标数据（OEE/FTT/产量/时间等）
  - `FTT_DATA`：实际/目标 FTT、趋势数据
  - `PRODUCTION_RATE_DATA`：达产率、计划/实际产量明细
  - `CYCLE_TIME_DATA`：12 工位节拍平衡数据
  - `EXCEPTION_DATA`：6 条异常事件
  - `ENV_DATA`：7 条温湿度点检数据

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：单栏纵向流式布局，渐变网格背景
- **容器宽度**：max-width 430px，居中显示
- **关键尺寸**：
  - 顶部导航栏：52px 高，深蓝渐变背景 + Logo + 通知铃铛
  - 上下文信息条：产线/日期/运行状态 Chip，可点击切换
  - 顶部标签栏：约 44px 高，sticky 定位，胶囊式 Tab 可滑动
  - 底部导航栏：60px + safe-area-inset-bottom，毛玻璃效果
  - Hero 概览卡片：综合 OEE + 三项摘要，蓝色渐变底
  - 核心指标区：2列卡片网格，图标角标 + 左侧色条
  - 指标卡片网格：明细页 2 列 CSS Grid
  - 触摸目标：最小 44x44px，间距至少 8px
  - 图表区域：200-220px 高，顶部渐变装饰条 + 图标标题
  - 内容区 padding：14px，padding-bottom 76px + safe-area

### 3.2 响应式适配
- **移动端（≤430px）**：满宽显示，首页 Hero + 核心指标2列，明细页2列
- **桌面浏览器查看**：430px 宽度居中，两侧留白
- **断点策略**：
  - 375px (iPhone SE): 最小支持宽度
  - 768px (iPad): 中等屏幕
  - 1024px: 大屏平板
  - 1440px: 桌面显示器

### 3.3 移动端核心适配策略（vs PC端）
| 维度 | PC 端 | 移动端 |
|------|-------|--------|
| 导航 | 顶部 Tabs | 底部导航 + 顶部标签栏 |
| 指标卡片 | 4 列 Row/Col | 首页 Hero + 2列核心指标，明细页 2 列 Grid |
| 数据表格 | Ant Design Table | 卡片列表布局 |
| 异常列表 | Table 带筛选列 | 标签筛选 + 卡片列表 |
| 图表高度 | 340px | 200-220px |
| 图表字号 | 12px | 9-11px |
| 间距 | 24px padding | 12px padding |
| 产线选择 | Select下拉 | Modal弹窗列表 |
| 时间选择 | DatePicker内联 | Modal弹窗DatePicker |

## 🎨 视觉规范

### 4.1 设计规范来源
**设计规范来源**：UI/UX Pro Max + Ant Design 主题 `/src/themes/antd-new`

**说明**：
- 基于 UI/UX Pro Max 的 BI Dashboard 设计模式（Data-Dense Dashboard）
- 颜色系统：Primary #458EF8, Secondary #6BAFFF, CTA #F59E0B
- 字体：Fira Sans（技术数据展示专用字体）
- 触摸目标：最小 44x44px，间距至少 8px
- 卡片样式：rounded-lg shadow-md p-6，hover:shadow-xl transition-shadow

### 4.2 自定义设计要点
**CSS 命名空间**：`.bi-mobile`（避免与 PC 端 `.bi-platform` 冲突）
**组件前缀**：`bim-`（BI Mobile 缩写）

**视觉层次优化（v2）**：
- **页面背景**：多层径向渐变网格（`--bi-bg-mesh`），告别单调纯色底
- **顶部导航**：渐变蓝色 `#2C6FE8 → #458EF8`，白色文字 + 毛玻璃 Logo + 通知红点
- **上下文 Chip 条**：产线（蓝渐变底）、日期（白底边框）、运行状态（绿底）
- **顶部 Tab**：胶囊式圆角按钮，选中态蓝色渐变 + 阴影，替代下划线样式
- **Hero 概览卡**：首页顶部蓝色渐变卡片，展示综合 OEE + 产量/FTT/达产率三项摘要
- **核心指标区**：2列卡片网格，6项快捷指标（图标角标 + 左侧色条）
- **明细页指标卡片**：
  - 右上角彩色图标角标（按类型 primary/success/warning/error/info）
  - 渐变浅色底色 + 右上角装饰圆点
  - 左侧 3px 彩色边条（圆角端点）
  - 明细页 2 列网格
- **图表容器**：顶部 3px 彩虹渐变装饰条 + 图标标题 + 右侧胶囊副标题
- **操作区**：产地/时间选择改为双 Chip 按钮（主色渐变 + 白底），替代 block 按钮
- **筛选标签**：按异常类型分色（故障红/物料橙/品质紫/换型蓝），选中填充对应色
- **异常卡片**：左侧 4px 类型色条 + 图标角标 + 描述区灰底圆角
- **工位卡片**：瓶颈工位红色左边框 + 渐变底色，统计数据网格化展示
- **底部导航**：毛玻璃背景 + 选中态图标胶囊底
- **区块标题**：图标 + 标题 + 右侧提示文字，划分内容层次

**交互状态**：
- 指标卡片：hover translateY(-2px) + shadow，active scale(0.97)
- 所有 Chip/Tab/按钮：active scale(0.96-0.97) 触觉反馈
- 数据列表项：active 背景变色

### 4.3 组件状态
- **顶部导航**：渐变背景，返回/更多按钮 active 态半透明白底
- **上下文 Chip**：产线/日期可点击打开弹窗，active scale 缩放反馈
- **顶部标签栏**：默认灰底胶囊 → 选中蓝色渐变 + 阴影
- **底部导航**：默认灰色 → 选中蓝色图标 + 胶囊底背景
- **筛选标签**：按类型分色边框 → 选中对应色填充
- **明细页指标卡片**：渐变底色 + 图标角标，hover/active 态位移缩放
- **产地选择弹窗**：选中项蓝底 + 右侧勾选图标
- **环境数据编辑**：行内 InputNumber 切换，OK 按钮保存
- **触摸目标**：所有可点击元素最小 44x44px，间距至少 8px
