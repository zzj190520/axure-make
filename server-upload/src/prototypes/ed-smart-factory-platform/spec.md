# 产线数字管理平台

## 📋 业务与功能

### 1.1 核心目标
> 新能源汽车电驱行业智能制造工厂一体化管控平台，打通研发、计划、生产、质量、设备、物流、能耗全链路数据，实现电驱生产全流程数字化、可视化、智能化管控，支撑降本、提质、增效、减耗核心目标。

### 1.2 功能清单

#### 数字孪生驾驶舱（重点模块）
- **三级看板**：车间现场 / 中层管理 / 高层决策，各 8 项 KPI 差异化展示
- **1:1 车间孪生地图**：八大功能区可视化布局，点击穿透查询
- **混线产线切换**：电机 / 电控 / 三合一总成产线产能分览
- **区域穿透面板**：产量、WIP、FTT、温湿度、关联设备、一键溯源
- **质量缺陷维度拆解**：高压绝缘 / 气密泄漏 / 压装偏差等饼图
- **生产环境监控**：温度 / 湿度 / 洁净度 / 防静电
- **能耗实时摘要**：功率 / 日用电 / 单台能耗 / 老化柜占比
- **分级预警闭环追踪**：紧急 / 重要 / 一般，绑定责任人与时限
- **AGV 物流动态**：孪生地图上 AGV 点位动画

#### 智能设备运维 SCADA+CMMS（重点模块）
- **SCADA 实时监控**：12 台核心精密设备六态卡片，点击查看详情抽屉
- **设备详情抽屉**：型号、运行时长、OEE、维保计划、实时参数、AI 风险
- **预防性维保**：维保工单表 + 维保计划时间线
- **AI 故障预测**：TOP3 高风险设备，概率 / 根因 / 措施 / 历史佐证
- **OEE 精细化分析**：三维度瀑布拆解 + 停机原因饼图 + 周趋势

#### EMS 精细化能耗管理（重点模块）

**1. 能耗数据采集（实时监控层）**
- **多维度采集点**：
  - 车间级：总用电量(kWh)、用水量(m³)、压缩空气(m³)
  - 产线级：电驱一线/二线/三线独立能耗计量
  - 设备级：单台设备实时功率(kW)、累计能耗
- **实时数据看板**：
  - 当前总功率、今日用电、本月累计、同比/环比
  - 单位产品能耗：kWh/台（电机/电控/总成分类统计）
  - 能耗强度指标：万元产值能耗、单台能耗趋势
- **能耗趋势分析**：
  - 24小时实时曲线（5分钟采样间隔）
  - 日/周/月/年多维对比
  - 峰谷平分段统计（峰:8-11h/17-21h, 平:11-17h, 谷:21-次日8h）
- **数据异常检测**：
  - 采集断点告警、数据跳变预警
  - 表计离线自动识别

**2. 环境参数管控（质量保障层）**
- **车间环境监控**：
  - 温度监控：18-28℃标准区间，超限预警
  - 湿度监控：40-65%RH，适配绝缘测试要求
  - 洁净度：ISO 7/8级洁净室实时监控（颗粒物≥0.5μm）
  - 粉尘浓度：定子绕线/转子压铸区域PM2.5/PM10监测
- **电驱专属环境适配**：
  - 精密装配区：恒温恒湿（±1℃/±3%RH）
  - 绝缘测试区：湿度≤50%RH强制管控
  - 高温老化区：温度80-150℃精准控制
  - 防静电监控：接地电阻<10Ω实时监测
- **异常预警机制**：
  - 三级预警：提示(黄)/警告(橙)/紧急(红)
  - 自动联动：超标自动启动空调/除湿机/净化设备
  - 历史追溯：环境异常时间段生产批次标记
  - 合规报告：自动生成环境监控日报/月报

**3. 节能分析优化（决策支持层）**
- **高能耗设备识别**：
  - TOP10能耗设备排名（老化柜/测试台/空压机/注塑机）
  - 设备能耗效率评估：产出/能耗比
  - 空载/待机能耗占比分析
- **高能耗工序分析**：
  - 工序能耗拆解：绕线→压铸→压装→测试→老化
  - 单产品工序能耗对比（标准vs实际）
  - 瓶颈工序能耗识别
- **节能优化建议**：
  - 峰谷电价优化：建议高能耗工序移至谷时段
  - 设备启停优化：非生产时段自动休眠建议
  - 空压机群控：压力带优化、泄漏检测
  - 老化柜节能：批次集中老化、温度曲线优化
  - 预计节能潜力：kWh/月、成本节约/月、碳减排量
- **绿色生产合规**：
  - 碳排放核算：范围1/2/3，符合ISO 14064
  - 碳强度指标：kgCO₂/台产品
  - 节能减排目标追踪：年度目标完成率
  - 合规报告生成：环评/能评/碳核查报告模板

**4. 能耗数据模型与计算规则**
- **能耗数据采集频率**：
  - 电表：实时功率(1秒)、累计电量(5分钟)
  - 水表：瞬时流量(10秒)、累计水量(15分钟)
  - 气表：瞬时流量(10秒)、累计气量(15分钟)
  - 环境传感器：温湿度(30秒)、洁净度(1分钟)、粉尘(1分钟)
- **单位产品能耗计算公式**：
  - 单台电机能耗 = 产线总能耗 ÷ 合格品产量
  - 分型号能耗 = Σ(各型号生产时段能耗) ÷ 各型号产量
  - 标准能耗基准：基于工艺BOM和历史最优值设定
- **峰谷平电价配置**：
  - 尖峰(1.8倍)：10:00-12:00, 18:00-20:00 (夏季7-9月)
  - 高峰(1.5倍)：8:00-10:00, 12:00-17:00, 20:00-22:00
  - 平价(1.0倍)：6:00-8:00, 22:00-24:00
  - 低谷(0.5倍)：0:00-6:00
- **碳排放计算因子**：
  - 电力：0.5810 kgCO₂/kWh (华东电网)
  - 天然气：0.2162 kgCO₂/m³
  - 自来水：0.0009 kgCO₂/m³
  - 压缩空气：0.0850 kgCO₂/m³

**5. 预警规则与联动控制**
- **能耗预警阈值**：
  - 日用电超目标10% → 黄色预警
  - 日用电超目标20% → 橙色预警
  - 日用电超目标30% → 红色预警
  - 单台设备功率突增50% → 立即预警
- **环境预警阈值**：
  - 温度：>28℃(黄)、>30℃(橙)、>32℃(红)
  - 湿度：>65%RH(黄)、>70%RH(橙)、>75%RH(红)
  - 洁净度：>352000粒/m³(黄)、>500000粒/m³(橙)、>1000000粒/m³(红)
  - 粉尘：PM2.5>75μg/m³(黄)、>115μg/m³(橙)、>150μg/m³(红)
- **自动联动控制**：
  - 温度超标 → 自动启动空调制冷/加大风量
  - 湿度超标 → 自动启动除湿机/关闭门窗
  - 洁净度超标 → 自动启动净化设备/报警停机
  - 粉尘超标 → 自动启动除尘系统/暂停产尘工序
- **预警通知机制**：
  - 黄色：系统消息 + 邮件通知责任人
  - 橙色：系统消息 + 邮件 + 短信通知责任人+主管
  - 红色：系统消息 + 邮件 + 短信 + 电话通知责任人+主管+厂长

#### 数据中台与智能分析（重点模块）
- **数据集成拓扑**：OT / MES / QMS / EMS → 数据中台
- **五层技术架构**：设备感知 → 采集 → 底座 → 业务 → 决策
- **数据资产目录**：工艺 / 质量 / 设备 / 能耗 / 追溯五大数据集
- **AI 模型注册中心**：6 大预测模型，准确率与运行状态
- **智能预判看板**：产能 / 交付 / 质量 / 设备 / 能耗 / 成本
- **自定义报表**：模板库 + 日报预览
- **实时数据吞吐监控**

- **APS 智能排产**：多约束排程、插单模拟、瓶颈预判
- **MES 生产执行**：ANDON、防错、在制品追踪

### 1.4 关键KPI指标

**能耗管理核心KPI**：
- 单位产品能耗（kWh/台）：目标值≤45，实际值实时监控
- 能耗成本占比（%）：能耗成本÷总产值，目标≤8%
- 峰谷平用电比例：谷电占比目标≥35%，峰电占比≤40%
- 设备空载率：目标≤5%，超过预警
- 节能目标完成率：年度节能目标完成百分比
- 碳排放强度（kgCO₂/台）：目标逐年递减5%
- 环境达标率：环境参数合格时长÷总时长，目标≥99.5%
- 预警响应时效：黄色<30min、橙色<15min、红色<5min

## 🔌 技术实现

### 4.1 API接口设计

**能耗数据采集接口**：
```
GET  /api/ems/energy/realtime          # 实时能耗数据
GET  /api/ems/energy/trend             # 能耗趋势数据
GET  /api/ems/energy/unit-consumption  # 单位产品能耗
POST /api/ems/energy/alerts            # 能耗预警查询
GET  /api/ems/energy/peak-valley       # 峰谷平统计
```

**环境参数接口**：
```
GET  /api/ems/environment/realtime     # 实时环境数据
GET  /api/ems/environment/history      # 历史环境数据
POST /api/ems/environment/alerts       # 环境预警查询
POST /api/ems/environment/linkage      # 联动控制指令
GET  /api/ems/environment/compliance   # 合规报告
```

**节能分析接口**：
```
GET  /api/ems/analysis/top-devices     # TOP10能耗设备
GET  /api/ems/analysis/process-breakdown  # 工序能耗拆解
GET  /api/ems/analysis/suggestions     # AI节能建议
GET  /api/ems/analysis/carbon          # 碳排放数据
POST /api/ems/analysis/report          # 生成分析报告
```

### 4.2 数据库表结构

**核心数据表**：
- `energy_meter_data`：电表采集数据（设备ID、时间戳、功率、累计电量）
- `water_meter_data`：水表采集数据（设备ID、时间戳、流量、累计水量）
- `air_meter_data`：气表采集数据（设备ID、时间戳、流量、累计气量）
- `environment_sensor_data`：环境传感器数据（传感器ID、时间戳、温度、湿度、洁净度、粉尘）
- `energy_consumption_daily`：日能耗汇总表（日期、车间、产线、用电、用水、用气、产量）
- `unit_product_energy`：单位产品能耗表（日期、产品型号、能耗值、标准值、偏差）
- `energy_alerts`：能耗预警记录（预警级别、触发时间、处理状态、责任人）
- `environment_alerts`：环境预警记录（预警级别、触发时间、联动动作、处理结果）
- `carbon_emission_daily`：日碳排放表（日期、电力碳排放、燃气碳排放、总排放、碳强度）
- `energy_saving_suggestions`：节能建议库（建议类型、预期节能量、实施状态、实际效果）

### 4.3 技术实现要点

**实时数据处理**：
- 使用 WebSocket 推送实时能耗数据（1秒刷新）
- 时序数据库存储高频采集数据（如 InfluxDB/TDengine）
- 数据聚合任务：5分钟/15分钟/小时/日多级聚合

**数据计算引擎**：
- 单位产品能耗：定时任务每小时计算一次
- 峰谷平统计：按电价时段自动分类统计
- 碳排放计算：实时累加，日结输出

**预警引擎**：
- 规则引擎配置预警阈值（支持动态调整）
- 实时流计算检测异常（如 Flink/Spark Streaming）
- 多级通知渠道集成（系统消息/邮件/短信/电话）

**可视化组件**：
- ECharts 实时曲线图（支持大数据量流畅渲染）
- 车间平面图 SVG + 热力图叠加
- 树形组件展示能耗层级结构
- 瀑布图展示工序能耗拆解
